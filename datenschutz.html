Datenschutz

Diese Website ist eine reine Informationsseite. Sie sammelt selbst keine persönlichen Daten.

Keine Cookies, kein Tracking

Wir setzen keine Cookies, nutzen keine Analyse- oder Werbedienste und binden keine Inhalte von Drittanbietern ein. Die Schrift wird von dieser Website selbst geladen, nicht von einem externen Dienst.

Keine Formulare

Es gibt kein Kontakt- oder Anmeldeformular. Über diese Website werden also keine Namen, E-Mail-Adressen oder Nachrichten übermittelt.

Hosting

Die Website wird über GitHub Pages bereitgestellt (GitHub, Inc., USA). Beim Aufruf verarbeitet GitHub technisch notwendige Daten, etwa die IP-Adresse, und kann sie aus Sicherheitsgründen speichern. Dabei können Daten in die USA übermittelt werden. Details stehen in der Datenschutzerklärung von GitHub.

Deine Rechte

Du kannst Auskunft über deine Daten verlangen sowie deren Berichtigung oder Löschung. Da wir selbst keine Daten speichern, betrifft das in der Regel nur die Server-Daten bei GitHub. Anfragen laufen persönlich über Lukas.
